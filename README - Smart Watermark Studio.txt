SMART WATERMARK STUDIO - VERSI APLIKASI WINDOWS

Cara menjalankan:
1. Klik dua kali: "Jalankan Smart Watermark Studio.cmd"
2. Aplikasi akan terbuka dalam jendela sendiri, bukan tab browser biasa.
3. Unggah foto dan watermark seperti biasa.

Semua pemrosesan dilakukan di perangkat Anda. Foto tidak diunggah ke internet.

File penting:
- watermark-smart.html       : mesin aplikasi
- Jalankan Smart Watermark Studio.cmd : launcher Windows

Untuk membuat shortcut Desktop: klik kanan launcher > Show more options > Send to > Desktop (create shortcut).
